📖 使用说明
  1. 选择上方模板：传代 / 接毒 / 送检 / 编号
  2. 选择模板后自动按参数生成数据（日期自动取当天）；改完参数点「重新生成」刷新表格，所有参数自动保存
  3. 点击表格单元格直接编辑内容，表头可修改列名
  4. 点击「添加行/列」扩展表格，点击「清空」重置
  5. 点击「📅 日期条」展开/收起日历；点击日期打开当天详情页：直接看到当天传代/接毒/编号/送检的明细小表格，可写备注、传照片，点底部「💾 保存当天记录」保存（左右箭头切前后天）
  6. 带紫点的日期表示有记录；点详情页里某块数据的「查看/编辑 →」会跳到该模板的表格继续编辑
  7. 数据自动保存在浏览器本地（原图存 IndexedDB，不压缩、不进 JSON）；在「⚙ 数据」里配置 GitHub 后，每次「保存当天记录」会把当天 JSON 与原图上传到仓库、导出 Excel 也会覆盖上传
  8. 导出 Excel：右下紫色「↓」按钮导出当前表格；详情页底部「导出 Excel」导出当天全部数据
  9. 导出时会弹出系统分享面板 → 选「存储到"文件"」即可存进手机文件 App 的任意文件夹（电脑端不支持分享时自动改为下载）
